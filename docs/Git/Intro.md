# Introduction to Git

Git is a distributed version control system used to track changes in files and collaborate on software projects.

## Why use Git?

- Track changes to your code and documentation.
- Restore previous versions of files.
- Work on different features using branches.
- Collaborate with other developers.
- Store projects on GitHub, GitLab or Bitbucket.

## How Git works

Git has three main areas:

1. **Working directory** — Files you're editing.
2. **Staging area** — Changes prepared for a commit.
3. **Repository** — Committed project history.

## Typical Git workflow

```bash
git status
git add .
git commit -m "Update documentation"
git push origin main
```

## Useful terminology

| Term | Description |
|---|---|
| Repository | A project tracked by Git |
| Commit | A saved snapshot of changes |
| Branch | An independent line of development |
| Merge | Combine changes from branches |
| Clone | Download a repository |
| Pull | Fetch and integrate remote changes |
| Push | Upload commits to a remote repository |
